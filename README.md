# Kapilart Salão — site institucional

Site estático (HTML, CSS e JavaScript puro) do Kapilart Salão, João Pessoa - PB.

- `index.html` — landing page (intro do logo, salão, loiros, vídeos, serviços, Amanda Luna, marcas, galeria, experiência, contato e localização)
- `agendamento.html` — formulário de agendamento que finaliza no WhatsApp (83) 99882-2099
- `css/style.css`, `js/main.js`, `js/booking.js`
- `img/` imagens em WebP otimizadas · `videos/` vídeos MP4 (H.264, 540×960) e capas

Para publicar basta servir a pasta raiz (Vercel, Netlify ou GitHub Pages), sem build.

Desenvolvido por Logotop Design.
